My goal is NOT to build just another chatbot.

I want to build a persistent AI companion that feels alive, emotionally intelligent, remembers the user, and continuously evolves.

My current stack:
- OpenAI GPT API (conversation)
- Qwen3-TTS (speech)
- VRM avatars
- Existing UI
- User authentication
- User dashboard
- Streak system
- Emotion graphs
- Analytics

Do NOT rewrite my project.

Instead, upgrade it into a true AI companion.

=========================
1. Persistent Memory
=========================

Each user should have long-term memory.

The companion should naturally remember things like:

- user's name
- nickname
- birthday
- hobbies
- favorite food
- favorite music
- favorite movies
- relationships
- goals
- dreams
- fears
- work
- college
- pets
- routines
- recurring problems
- important life events
- previous conversations

The companion should automatically decide what deserves permanent memory instead of storing every message.

=========================
2. Dynamic Personality
=========================

The companion should gradually build an understanding of the user.

Examples:

"I love astronomy."
→ remember

"I'm stressed every Monday."
→ remember

"My exam is next week."
→ temporary reminder

"I hate horror movies."
→ preference

The companion should naturally reference memories later.
