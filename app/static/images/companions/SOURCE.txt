Additional GitHub anime-style VRoid replacements
================================================

Source: madjin/vrm-samples on GitHub
Repository: https://github.com/madjin/vrm-samples
License notes: The repository documents VRoid sample model usage and links to
the official VRoid Studio conditions of use. These are VRoid Studio sample
models and should be used under those conditions.

Downloaded local assets:
- rose.vrm: Vivi.vrm
  Download URL: https://raw.githubusercontent.com/madjin/vrm-samples/master/vroid/beta/Vivi.vrm
  Display name in app: Vivi
- robert.vrm: Sakurada_Fumiriya.vrm
  Download URL: https://raw.githubusercontent.com/madjin/vrm-samples/master/vroid/beta/Sakurada_Fumiriya.vrm
  Display name in app: Sakurada

These files replace the previous low-poly OpenGameArt test characters so the
secondary male and female companions are cute anime-styled VRoid characters.
The internal companion ids remain rose and robert to preserve voice mappings.
The active UI uses all four VRM files with a cache-busting query string.

The Your Emora character stage renders these VRM humanoid models with Three.js
and @pixiv/three-vrm. Their skeleton bones are animated in WebGL for idle and
speaking motion, and their VRM mouth/blink/look-at/facial expressions are
driven by local Piper audio playback state. The VRoid files expose A/I/U/E/O
mouth blendshapes where available, which the stage maps into simple viseme
groups for lip movement.
